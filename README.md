Gesture Studio

Draw and create effects in the air with hand gestures, using your webcam. Gesture Studio is a single HTML file that runs in the browser. Open it in Chrome or Edge, allow camera access, and it tracks your hands in real time.

Features

Writing mode

Point with your index finger to draw
Make a fist to stop drawing
Hold an open palm for one second to clear the canvas
The mouse also works for drawing

Effects mode

Clap both hands for fireworks
Hold an open palm for a chakra animation
Make a peace sign for sparkles
Point with your index finger for a magic trail
Make a fist for a shockwave
Give a thumbs up for hearts
Click with the mouse for fireworks

Buttons

Clear, Undo, and Save PNG (downloads your drawing)
Requirements
A webcam
Chrome or Edge
An internet connection, because the hand-tracking model loads from a CDN
How to run
Save the file as index.html.
Double-click it to open it in Chrome or Edge.
Click Start camera and allow access when asked.

If the camera doesn't start, close other apps that use it, such as Zoom or Teams, then try again. If camera permission was blocked, click the camera icon in the address bar, set it to Allow, and press Start camera again.
